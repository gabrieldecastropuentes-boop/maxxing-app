# 🔐 COLETA DE CREDENCIAIS

Para configurar todas as integrações, preciso das seguintes informações:

---

## 📋 INFORMAÇÕES NECESSÁRIAS

### 1️⃣ GOOGLE ANALYTICS 4
**O que preciso:** Measurement ID (formato: `G-XXXXXXXXXX`)

**Como obter:**
1. Acesse: https://analytics.google.com
2. Se não tiver conta, crie uma (gratuito)
3. Crie uma propriedade Web
4. Vá em **Administração** → **Fluxo de dados** → **Web**
5. Copie o **ID de medição** (começa com `G-`)

**Exemplo:** `G-ABC123XYZ`

---

### 2️⃣ FACEBOOK PIXEL
**O que preciso:** Pixel ID (apenas números)

**Como obter:**
1. Acesse: https://business.facebook.com
2. Se não tiver conta Business, crie uma (gratuito)
3. Vá em **Eventos** → **Pixels**
4. Clique em **Criar Pixel**
5. Escolha "Usar código de integração"
6. Copie o **ID do Pixel** (só números, sem letras)

**Exemplo:** `123456789012345`

---

### 3️⃣ TAWK.TO (CHAT)
**O que preciso:** Property ID e Widget ID

**Como obter:**
1. Acesse: https://www.tawk.to
2. Clique em **Sign Up Free** (gratuito)
3. Crie sua conta
4. Após criar, você verá um código assim:
   ```
   https://embed.tawk.to/507f1f77d9b2c17aec060e5c/default
   ```
5. Copie os dois valores:
   - **Property ID:** `507f1f77d9b2c17aec060e5c` (primeira parte)
   - **Widget ID:** `default` (segunda parte, geralmente é "default")

**Exemplo:**
- Property ID: `507f1f77d9b2c17aec060e5c`
- Widget ID: `default`

---

### 4️⃣ DOMÍNIO DO SITE
**O que preciso:** URL completa do seu site

**Exemplo:** 
- `https://meusite.com.br`
- `https://www.meusite.com.br`
- `https://glowmax.app`

**Se ainda não tiver domínio:** Use o domínio temporário ou deixe como está (`https://glowmax.app`)
